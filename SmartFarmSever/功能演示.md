### 2. 分页工具类PageDiv
**功能特点：**
- 支持泛型，可处理任意类型数据
- 自动计算总页数、是否有上一页/下一页等状态
- 提供分页信息字符串
- 支持静态工厂方法创建分页对象

**使用示例：**
```java
// 创建分页对象
List<User> users = userService.findAll();
PageDiv<User> pageDiv = PageDiv.of(1, 10, users.size(), users);

// 获取分页信息
String pageInfo = pageDiv.getPageInfo(); // "第 1 页，共 5 页，每页 10 条，共 50 条记录"
boolean hasNext = pageDiv.isHasNext();   // true
int nextPage = pageDiv.getNextPage();    // 2
```

### 3. MD5加密工具类MD5Util
**功能特点：**
- 支持普通MD5加密
- 支持带盐值的MD5加密（提高安全性）
- 支持大小写转换
- 提供密码验证功能
- 支持随机盐值生成

**使用示例：**
```java
// 普通MD5加密
String encrypted = MD5Util.encrypt("hello world");
// 结果: 5d41402abc4b2a76b9719d911017c592

// 带盐值加密
String encryptedWithSalt = MD5Util.encrypt("hello world", "custom-salt");
// 结果: 不同的加密结果

// 密码验证
boolean isValid = MD5Util.verify("hello world", encrypted); // true

// 生成随机盐值
String salt = MD5Util.generateSalt(); // 8位随机字符串
```

### 4. 主键获取工具类IdGenerator
**功能特点：**
- 雪花算法ID生成（分布式唯一ID，支持高并发）
- 自增ID生成
- 时间戳ID生成
- 纳秒ID生成
- UUID风格ID生成
- 带前缀ID生成
- 基于日期的ID生成
- 随机数字/字符串ID生成

**使用示例：**
```java
// 雪花算法ID（推荐用于分布式系统）
IdGenerator idGenerator = new IdGenerator();
long snowflakeId = idGenerator.nextId(); // 19位长整型

// 自增ID
long incrementId = IdGenerator.generateIncrementId(); // 1, 2, 3...

// 时间戳ID
long timestampId = IdGenerator.generateTimestampId(); // 当前时间戳

// UUID风格ID
String uuidStyleId = IdGenerator.generateUuidStyleId(); // 32位字符串

// 带前缀ID
String prefixedId = IdGenerator.generatePrefixedId("USER_"); // USER_1703123456789123

// 基于日期的ID
String dateBasedId = IdGenerator.generateDateBasedId("ORDER_"); // ORDER_202312211234560001
```

## 运行方式

### 方式1：使用Maven（推荐）
```bash

mvn clean compile

# 运行项目

```

### 方式2：使用IDE
1. 导入Maven项目
2. 运行SpringBootApplication.java
3. 访问 http://localhost:8080/api/test/health

## 注意事项
1. 确保Java 8环境已正确安装
2. 如需使用数据库功能，请先创建MySQL数据库

5. 分页工具类适用于内存分页，大数据量建议使用数据库分页
